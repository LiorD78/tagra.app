Cosa ti offre

Zero trasferimenti
manuali di file

DKV LIVE® è un servizio di telematica che preleva i dati del cronotachigrafo e della carta conducente dai tuoi veicoli tramite la rete mobile e li memorizza su un server SFTP sicuro.

TAGRA si collega a quel server e importa i dati automaticamente, secondo la pianificazione che scegli — da una volta al giorno a ogni poche ore.

Il risultato: i dati di ogni veicolo della tua flotta arrivano direttamente in TAGRA, pronti per la valutazione, i report delle infrazioni e l'archiviazione. Nessuna chiave di download, nessun giro per il piazzale, nessuna scadenza mancata.

DKV LIVE® Telematica + TAGRA = automazione completa

Se paghi già per la telematica DKV LIVE®, non hai bisogno di alcun hardware aggiuntivo per portare i dati del cronotachigrafo in TAGRA. Basta inserire le tue credenziali DKV nella schermata Data Import di TAGRA ed è fatto.

Guida alla configurazione

Passo dopo passo

Configurare l'importazione DKV LIVE® in TAGRA richiede circa due minuti. Lo fai una sola volta — da quel momento in poi, TAGRA preleva i dati automaticamente.

01
Apri Data Import

Nella finestra principale di TAGRA, fai clic su Import dat (Data Import) nel menu a sinistra. È qui che configuri il collegamento tra DKV LIVE® e TAGRA.

02
Aggiungi una nuova importazione

Nel pannello sinistro della schermata Data Import, fai clic su Add import. Si apre una finestra di configurazione.

03
Configura la connessione

Compila la finestra di configurazione:

  • Import name — un'etichetta a tua scelta (ad es. «DKV»)
  • Folder — inserisci / (una singola barra)
  • Run interval — ogni quanto TAGRA deve recuperare i dati (consigliato: 1d per un recupero giornaliero)
  • SFTP server — sftp.styletronic.eu
  • Port — 22
  • Username and password — le tue credenziali DKV LIVE®

Conferma con OK.

04
Esegui la prima importazione

Fai clic sulla tua nuova connessione (si evidenzia in blu) e premi Run import. TAGRA scarica immediatamente gli ultimi file del cronotachigrafo e della carta conducente dal server DKV. Al termine, torna alla schermata principale e inizia la tua valutazione.

Automatico o manuale?

Impostalo una volta,
e non pensarci più

Il campo Run interval determina ogni quanto TAGRA recupera i dati da DKV LIVE®:

  • 1d — una volta al giorno (consigliato)
  • 12h — ogni 12 ore
  • 6h, 3h, 1h — più frequente
  • 0s — solo manuale (fai clic tu stesso su Run import)

Consigliamo almeno una frequenza giornaliera, così i tuoi dati restano aggiornati e sono sempre rispettate le finestre legali di scarico di 28 e 90 giorni.

Perché è importante 28 e 90 giorni sono scadenze di legge

Le normative UE richiedono che i dati della carta conducente siano scaricati almeno ogni 28 giorni e i dati dell'unità di bordo del cronotachigrafo almeno ogni 90 giorni.

Con DKV LIVE® + TAGRA impostati su una pianificazione giornaliera, queste scadenze vengono rispettate automaticamente. Hai inoltre una traccia archiviata e ordinata per qualsiasi controllo.

FAQ

Quali versioni di TAGRA supportano DKV LIVE®?
Tutte le versioni attuali di TAGRA — TAGRA 1, 2, 4, 6 e MAX — supportano l'importazione DKV LIVE® dalla versione 345 in poi. Il numero di versione è indicato nella parte inferiore della finestra di TAGRA. Se hai una build più vecchia, aggiorna tramite l'updater integrato nell'app — gli aggiornamenti sono compresi nella quota di rinnovo annuale.
Dove trovo le mie credenziali DKV LIVE®?
Dal tuo account manager DKV Mobility o dal rappresentante commerciale. TAGRA ha bisogno di un nome utente e una password SFTP validi per il server DKV LIVE® — gli stessi che utilizzeresti per accedere direttamente al servizio. Non gestiamo noi l'attivazione degli account DKV.
Ogni quanto TAGRA dovrebbe recuperare i dati da DKV LIVE®?
Consigliamo almeno una volta al giorno (intervallo 1d). Questo mantiene i tuoi dati aggiornati e garantisce che tu sia ben all'interno delle finestre legali di scarico di 28 e 90 giorni. Puoi impostarlo ogni poche ore se preferisci una valutazione quasi in tempo reale — entrambe le opzioni funzionano bene.
Cosa succede se l'importazione fallisce o restituisce un errore?
Per prima cosa, controlla di nuovo il server SFTP (sftp.styletronic.eu), la porta (22) e le tue credenziali. Se sono corretti e l'importazione continua a fallire, contattaci via e-mail all'indirizzo helpdesk@tagra.app. Il messaggio di errore nell'elenco delle importazioni di TAGRA ci aiuta a diagnosticare rapidamente il problema.
Ho bisogno di DKV LIVE® per lo scarico remoto del cronotachigrafo?
No. DKV LIVE® è uno dei diversi modi per portare i dati del cronotachigrafo in TAGRA — è un'ottima opzione se usi già il servizio di telematica DKV. In caso contrario, TAGRA accetta anche i file standard .DDD, .C1B e .V1B provenienti da qualsiasi altro strumento di scarico del tachigrafo. Contattaci se desideri un consiglio.
TAGRA è ufficialmente partner di DKV?
TAGRA importa i dati dal servizio SFTP di DKV LIVE® utilizzando le tue credenziali DKV. Si tratta di una funzione di interoperabilità tecnica, non di una partnership formale o di un'approvazione. DKV LIVE® è un marchio registrato di DKV Mobility.
L'importazione DKV LIVE® è inclusa nella mia licenza TAGRA?
Sì. La funzione Data Import (inclusa la connettività DKV LIVE®) fa parte di ogni licenza TAGRA attuale senza costi aggiuntivi. Paghi solo la normale licenza TAGRA e il normale abbonamento DKV LIVE® — nulla di più.
