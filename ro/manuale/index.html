Întrebări frecvente despre instalare
Pe ce versiuni de Windows funcționează TAGRA?
TAGRA funcționează pe Windows 10 și Windows 11. Este o aplicație desktop — se instalează pe computer, nu într-un browser, și funcționează offline după instalare.
De ce trebuie să instalez Firebird și Desktop Runtime?
Firebird este baza de date care stochează datele dumneavoastră de tahograf pe propriul computer, iar Microsoft Desktop Runtime este componenta pe care rulează aplicația. Ambele sunt instalate automat ca parte a configurării TAGRA — nu trebuie să le descărcați separat. Dacă acestea sunt deja instalate pe computer, programul de instalare omite această etapă.
Pot instala TAGRA pe mai multe computere?
Da. Licența permite instalarea pe mai multe computere din cadrul aceleiași societăți. Baza de date poate fi partajată prin rețeaua locală, astfel încât mai multe persoane să lucreze cu aceleași date, în loc să păstreze copii separate.
Unde găsesc cheia de licență?
Cheia este emisă după achiziție și se introduce direct în meniul de licență din software. În perioada de probă de 30 de zile nu este necesară nicio cheie — software-ul complet funcționează fără restricții.
Instalarea TAGRA necesită drepturi de administrator?
Da. Instalarea scrie în Program Files și înregistrează serviciul bazei de date, astfel încât contul care efectuează instalarea trebuie să aibă drepturi de administrator pe computer. Utilizarea obișnuită ulterioară nu necesită aceste drepturi de administrator.
Întâmpin dificultăți în timpul instalării — cine mă poate ajuta?
Echipa noastră de asistență tehnică vă ajută direct. Scrieți la helpdesk@tagra.app și descrieți la care dintre etapele instalării apare problema — o captură de ecran cu eroarea accelerează considerabil soluționarea.
