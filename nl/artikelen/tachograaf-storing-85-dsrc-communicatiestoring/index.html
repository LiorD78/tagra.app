Foutcode · VDO DTCO 4.1 (display 085)

DSRC-communicatiestoring — foutcode 85 van de tachograaf

Truck Data TechnologyBijgewerkt september 20263 min leestijd

Code 85 betekent dat uw tachograaf de communicatie met de externe DSRC-module heeft verloren — de eenheid die voor wegcontroles op afstand wordt gebruikt — via de CAN-bus van het voertuig.

Ernst
Laag

Heeft geen gevolgen voor het registreren van uw rijtijd, pauzes of rust.

Betrokken verbinding
CAN-verbinding met DSRC

Communicatie tussen de DTCO 4.1 en de externe module — niet de module zelf.

Displaycode
085

Geregistreerd als DTC 002D80 op de VDO DTCO 4.1.

Wat het betekent

Wat deze code betekent

DSRC staat voor Dedicated Short-Range Communication. Het is de externe module waarmee handhavingsinstanties langs de weg uw tachograaf op afstand kunnen ondervragen, zonder uw voertuig te stoppen, wanneer u een controlepunt passeert. De module is via de CAN-bus van het voertuig aangesloten op de VDO DTCO 4.1.

Code 85, DSRC-communicatiefout, betekent dat de DTCO 4.1 deze CAN-busverbinding heeft verloren — geregistreerd als DTC 002D80. Dit verschilt van code 84 (interne DSRC-storing), die een probleem in de module zelf aangeeft: code 85 betreft specifiek een onderbreking van de communicatie tussen de twee eenheden.

Wat u nu moet doen

Wat u nu moet doen

De handleiding vermeldt twee stappen voor code 85:

  1. Bevestig het bericht op het scherm.
  2. Laat bij herhaling een erkende werkplaats controleren of de CAN-busparameters, de bekabeling tussen de DTCO 4.1 en de DSRC-module en de antenneaansluiting in orde zijn.

Er is geen verplichting om te stoppen met rijden. Plan het bezoek aan de werkplaats bij de eerstvolgende gelegenheid.

Uw tachograaf registreert deze storing — TAGRA leest deze uit

TAGRA verhelpt geen DSRC-communicatiefout — alleen een erkende werkplaats kan de bedrading, connector of module repareren die de fout veroorzaakt. Maar zodra code 85 in het geheugen van de tachograaf en op uw bestuurderskaart is opgeslagen, vindt TAGRA deze in uw uitgelezen gegevens, beoordeelt en documenteert TAGRA de code — precies wat u nodig hebt bij een wegcontrole en wanneer u de fout bij de werkplaats meldt.

Waarom het gebeurt

Waarom het gebeurt

Volgens de handleiding heeft code 85 drie mogelijke oorzaken:

  • A storing in de bedrading of connector op de CAN-verbinding tussen de DTCO 4.1 en de externe DSRC-module.
  • Het DSRC-module reageert niet op de bus — door voedingsverlies, een interne storing of een configuratieverschil.
  • Elektrische interferentie of een losse verbinding die de CAN-communicatie verstoort.

Omdat de DSRC-module alleen de ondervraging op afstand bij wegcontroles verzorgt, onderbreekt een communicatiefout hierin de normale registratie van rijtijd, ander werk, beschikbaarheid of rust niet.

Ernst

Kunt u blijven rijden?

Ja. Code 85 is ingedeeld als lage ernst . De code heeft geen invloed op de kernfunctie voor de registratie van de tachograaf en er is geen verplichting om het voertuig te stoppen.

Het enige praktische gevolg is dat de ondervraging op afstand via DSRC bij een controlepunt langs de weg mogelijk niet correct werkt totdat de communicatie is hersteld — in dat geval voert een controleur gewoon een normale controle in de cabine uit. Bevestig de melding en laat, als de storing terugkomt, de CAN-bedrading, de connector en de DSRC-module bij uw volgende bezoek aan een erkende werkplaats controleren.

Vragen & antwoorden

Veelgestelde vragen

Wat is het verschil tussen code 84 en code 85?

Code 84 (interne DSRC-storing) betekent dat het probleem in de DSRC-module zelf zit. Code 85 (DSRC-communicatiefout) betekent dat de module en de DTCO 4.1 via de CAN-bus niet met elkaar kunnen communiceren — de module kan in orde zijn, maar de verbinding tussen de module en de tachograaf is verbroken.

Kan ik blijven rijden met een DSRC-communicatiefout (code 85)?

Ja. In de handleiding is code 85 ingedeeld als lage ernst. De code heeft geen invloed op de registratie van rijtijd, pauzes of rust — bevestig de melding en maak, als de storing terugkomt, een afspraak voor controle in een werkplaats.

Heeft code 85 invloed op de gegevens op mijn bestuurderskaart?

Nee. De DSRC-module en de bijbehorende CAN-verbinding verzorgen alleen de ondervraging op afstand — zij spelen geen rol bij de registratie van uw rijtijd, ander werk, beschikbaarheid of rust. Daarom is deze storing in de handleiding ingedeeld als lage ernst.

Wat moet een werkplaats voor code 85 controleren?

De CAN-busparameters, de bekabeling tussen de DTCO 4.1 en de externe DSRC-module en de antenneaansluiting, zoals in de handleiding staat. Een terugkerende storing wijst eerder op een probleem met de bedrading of de verbinding dan op een eenmalige storing.
