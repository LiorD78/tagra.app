Interne GNSS-storing — foutcode 82 van de tachograaf

Truck Data TechnologyBijgewerkt september 20263 min leestijd

Code 82 betekent dat uw tachograaf een interne storing heeft vastgesteld die de GNSS-positiebepalingsontvanger beïnvloedt.

Ernst
Gemiddeld

Bevestiging en raadpleging van een werkplaats vereist.

Betroffen onderdeel
GNSS-ontvanger

Het onderdeel dat de positie van uw tachograaf voor de registratie bepaalt.

000C31

Schakel de voeding uit en weer in, maak een testrit en vervang het onderdeel als de storing aanhoudt.

Wat het betekent

Wat deze code betekent

Moderne digitale tachografen gebruiken een ingebouwde GNSS-ontvanger om de positie van het voertuig aan het begin en einde van een dienst en met vaste intervallen tijdens het rijden te registreren. Code 82, interne GNSS-storing, betekent dat de tachograaf een interne storing in deze ontvanger heeft gedetecteerd — niet gewoon een verloren signaal.

Volgens de handleiding is de ernst van deze storing Gemiddeld. Bij een Stoneridge SE5000 wordt dezelfde storing in het werkplaatsdiagnoseapparaat geregistreerd als DTC 000C31.

Verwar dit niet met code 83

Code 82 betekent dat de GNSS-ontvanger of de antenne zelf defect is. Code 83, GNSS ontbreekt, betekent dat de ontvanger werkt, maar eenvoudigweg geen positiesignaal ontvangt. Zie de volledige vergelijking op die pagina.

Wat u nu moet doen

Wat u nu moet doen

De handleiding geeft voor code 82 één instructie:

  1. Bevestig het bericht op het display van de tachograaf.
  2. Raadpleeg een erkende werkplaats.

Als uw voertuigunit een Stoneridge SE5000 is: De werkplaatsprocedure voor DTC 000C31 bestaat uit het spanningsloos en weer onder spanning zetten van de tachograaf en het uitvoeren van een proefrit. Als de storing aanhoudt, moet de ontvanger worden vervangen.

Uw tachograaf registreert deze storing — TAGRA leest deze uit

TAGRA repareert geen GNSS-storing — alleen een erkende werkplaats kan een defecte ontvanger of antenne vervangen. Maar zodra code 82 in het geheugen van de tachograaf en op uw bestuurderskaart is opgeslagen, vindt TAGRA deze in uw uitgelezen gegevens, beoordeelt en documenteert deze — precies wat u nodig hebt bij een wegcontrole en wanneer u bij de werkplaats een garantieclaim indient.

Waarom het gebeurt

Waarom het gebeurt

Volgens de handleiding heeft code 82 drie mogelijke oorzaken:

  • een interne storing in het eigen GNSS-apparaat van de tachograaf;
  • een kortsluiting in de externe GNSS-antenne, indien aanwezig; of
  • geen verbinding met de externe GNSS-antenne.

Bij een Stoneridge SE5000 (DTC 000C31) wordt hetzelfde onderliggende probleem beschreven: de interne GNSS-ontvanger levert geen positiegegevens meer.

Ernst

Kunt u blijven rijden?

De handleiding classificeert code 82 als Gemiddelde ernstU moet de melding bevestigen en een erkende werkplaats raadplegen — het is geen storing waarvoor u onmiddellijk moet stoppen.

Omdat dit gevolgen heeft voor de ontvanger die verantwoordelijk is voor de positiegegevens van de tachograaf, mag u dit niet onbeperkt laten voortduren: plan tijdig een controle bij de werkplaats in, in plaats van te wachten tot een terugkerend probleem vanzelf verdwijnt. Bij een Stoneridge-unit zijn het spanningsloos en weer onder spanning zetten en een proefrit de eerste stappen; als de storing terugkeert, moet de ontvanger worden vervangen.

Vragen & antwoorden

Veelgestelde vragen

Wat is het verschil tussen code 82 en code 83?

Code 82 betekent dat de GNSS-ontvanger of de antenne zelf defect is — een interne storing, een kortsluiting in de externe antenne of geen verbinding ermee. Code 83 betekent dat de ontvanger werkt, maar gedurende drie uur cumulatieve rijtijd geen positiegegevens heeft ontvangen. Zie GNSS ontbreekt (code 83) voor meer informatie.

Kan ik blijven rijden met een interne GNSS-storing (code 82)?

De handleiding classificeert deze als Gemiddelde ernst: bevestig de melding en raadpleeg een erkende werkplaats. Het is geen storing waarvoor u onmiddellijk moet stoppen, maar u moet de controle wel tijdig inplannen in plaats van de storing te laten terugkeren.

Wat betekent DTC 000C31 op een Stoneridge SE5000?

DTC 000C31 is de werkplaatscode van de Stoneridge SE5000 voor een interne GNSS-storing — de interne GNSS-ontvanger levert geen positiegegevens meer. De procedure bestaat uit het spanningsloos en weer onder spanning zetten van de tachograaf en een proefrit; als de storing aanhoudt, moet de ontvanger worden vervangen.

Waardoor ontstaat een interne GNSS-storing in een digitale tachograaf?

Volgens de handleiding kunnen drie zaken code 82 veroorzaken: een interne storing in het eigen GNSS-apparaat van de tachograaf, een kortsluiting in de externe GNSS-antenne (indien aanwezig) of geen verbinding met de externe GNSS-antenne.
