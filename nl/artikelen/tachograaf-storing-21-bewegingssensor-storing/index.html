Storing bewegingssensor 21: wat deze betekent en wat u moet doen

Truck Data TechnologyBijgewerkt september 20263 min lezen

Code 21 betekent: de tachograaf heeft de communicatie met de bewegingssensor verloren — de sensor die op de versnellingsbak is gemonteerd. Volgens de handleiding kan de oorzaak een onderbreking in de voeding van de sensor, beschadigde bedrading, ontbrekende pulsen, een afwijking in de teller of een niet-toegestane vervanging van de sensor zijn. U kunt dit niet zelf repareren — een controle bij een erkende werkplaats is vereist (met een vergunning van de voorzitter van GUM).

Prioriteit
Hoog

Hiervoor is een inspectie bij een erkende werkplaats vereist en u kunt de reparatie niet zelf uitvoeren.

Heeft betrekking op het onderdeel
Bewegingssensor / bewegingssensor

Communicatie tussen de voertuigeenheid en de bewegingssensor op de versnellingsbak.

VDO-code
021

EventFaultType 0x09 „motion data error” overeenkomstig bijlage IC.

Wat deze code betekent

Wat deze code betekent

Bewegingssensor, dat wil zeggen de bewegingssensor, is op de versnellingsbak gemonteerd en zendt snelheidspulsen naar de voertuigeenheid (VU) van de tachograaf. Code 21, storing van de bewegingssensor, betekent dat deze communicatie is verstoord — de voertuigeenheid ontvangt geen correcte bewegingsgegevens van de bewegingssensor.

Verwar deze niet met code 16

Code 16, een sensorstoring na een zelftest, betekent dat de sensor zelf tijdens zijn eigen diagnose een intern probleem heeft gemeld. Code 21 betreft daarentegen de communicatie tussen de sensor en de voertuigeenheid — bedrading, voeding of koppeling — en duidt niet noodzakelijk op een storing in de sensor zelf.

Wat u nu moet doen

Wat u nu moet doen

  1. Het bericht moet worden bevestigd, door op het display op OK te drukken.
  2. Rijd naar een veilige plaats om te stoppen.
  3. U moet een afdruk van de tachograaf van de huidige dag maken.
  4. Handmatige registraties maken alle verdere activiteiten op de achterzijde van deze afdruk registreren — totdat de storing is verholpen.
  5. Informeer de wagenparkbeheerder en zo snel mogelijk een erkende werkplaats bereiken.

Doorrijden zonder handmatige registraties terwijl u al op de hoogte bent van de storing van de bewegingssensor is in alle EU-landen een ernstige overtreding.

Wat u niet moet doen

Wat u niet moet doen

  • Probeer deze niet zelf te vervangen of te repareren van de bewegingssensor — ongeoorloofde interventie is een van de mogelijke oorzaken van deze code en kan tijdens een controle worden aangemerkt als een poging tot manipulatie.
  • Verwar deze niet met code 16 (storing van de bewegingssensor na de zelftest) — dit is een ander probleem, binnen de bewegingssensor zelf.
  • Rijd niet verder zonder handmatige registraties in te voeren. — in tegenstelling tot een storing met lage prioriteit vereist code 21 een onmiddellijke reactie.
  • Negeer een terugkerende melding niet op hetzelfde voertuig — dit duidt op een aanhoudend probleem met de sensor of de bedrading.
Waarom verschijnt deze code?

Waarom verschijnt deze code?

Volgens de handleiding kan code 21 worden veroorzaakt door:

  • onderbreking van de voeding van de bewegingssensor;
  • beschadigde of losse bedrading tussen de bewegingssensor en de voertuigeenheid;
  • ontbrekende pulsen van de bewegingssensor;
  • kilometerteller komt niet overeen — verschil tussen de gegevens van de bewegingssensor en een andere bron van bewegingsgegevens; of
  • ongeoorloofde vervanging van de sensor — de koppeling van een nieuwe bewegingssensor met de voertuigeenheid komt niet overeen.

Zoals EventFaultType 0x09 („fout in de bewegingsgegevens”) volgens bijlage IC bij Verordening (EU) 2016/799 valt code 21 onder dezelfde groep als de codes 020, 022 en 087 — de storing wordt opgeslagen in het massageheugen van de voertuigeenheid en op de bestuurderskaart.

Kunt u verder rijden?

Kunt u verder rijden?

Kort gezegd: ja, maar alleen om de dichtstbijzijnde veilige stopplaats te bereiken. Code 21 heeft hoge prioriteit, omdat de bewegingssensor de bron is van gegevens over snelheid en afgelegde afstand en de storing ervan dus de betrouwbaarheid van de volledige registratie van de rijtijd beïnvloedt. Vanaf het moment waarop u kennis krijgt van de storing, moet u verder rijden met uitsluitend handmatige registraties van de activiteiten op de achterzijde van de afdruk van die dag — totdat het voertuig bij een erkende werkplaats is gerepareerd.

Formeel is artikel 37 van Verordening 165/2014 van toepassing: repareer de storing zodra de omstandigheden dit toelaten en als het voertuig niet binnen één week na het vaststellen van de storing naar de vestiging kan terugkeren, moet de reparatie onderweg worden uitgevoerd.

Gevolgen voor het bedrijf

Gevolgen voor het bedrijf

De bewegingssensor levert gegevens over de beweging van het voertuig, waarop de volledige registratie van rijtijd, pauzes en rusttijden is gebaseerd. Handhavingsinstanties nemen een storing van de bewegingssensor serieus — het is een van de onderdelen die het vaakst worden gecontroleerd wanneer manipulatie van de tachograaf wordt vermoed, omdat het ongeoorloofd vervangen van de sensor een van de mogelijke oorzaken van code 21 is.

Als de bestuurder blijft rijden zonder de vereiste handmatige registraties, of als het bedrijf de reparatie niet binnen een redelijke termijn kan documenteren, kan de wegcontrole leiden tot het vastleggen van een overtreding wegens het niet nakomen van de reparatieverplichting uit artikel 37 — en, als manipulatie wordt vermoed, ook tot verdere onderzoeksprocedures.

Vragen en antwoorden

Veelgestelde vragen

Op het VDO-display zie ik “motion sensor fault” — kan ik blijven rijden?

Kort gezegd: ja — om een veilige stopplaats te bereiken. Vervolgens moet u: (1) op OK drukken om te bevestigen, (2) een afdruk van de tachograaf voor de desbetreffende dag maken, (3) alle daaropvolgende activiteiten handmatig op de achterzijde van deze afdruk registreren, (4) de wagenparkbeheerder informeren en (5) zo snel als de omstandigheden toestaan een erkende werkplaats bereiken. Doorrijden zonder handmatige registraties nadat u zich bewust bent geworden van de storing, is in alle EU-landen een ernstige overtreding.

Waardoor ontstaat code 21?

Volgens de handleiding kan de oorzaak een onderbroken voeding van de bewegingssensor, beschadigde of losse bedrading tussen de sensor en de voertuigeenheid, ontbrekende pulsen van de sensor, een afwijking in de teller of een niet-toegestane vervanging van de sensor zijn.

Wat is het verschil tussen code 21 en code 16?

Code 16 betekent dat de sensor zelf na zijn eigen zelftest een intern probleem heeft gemeld. Code 21 betreft de communicatie tussen de sensor en de voertuigeenheid — bedrading, voeding of koppeling — en duidt niet noodzakelijk op een storing in de sensor zelf.

Kan een niet-toegestane vervanging van de bewegingssensor code 21 veroorzaken?

Ja. Als de nieuwe bewegingssensor niet correct aan de voertuigeenheid wordt gekoppeld in een erkende werkplaats, meldt de tachograaf een storing van de bewegingssensor. Dit is een van de redenen waarom code 21 een hoge prioriteit heeft en een controle in een werkplaats vereist, in plaats van een poging om de storing zelf te verhelpen.
