Common questions about installation
Which versions of Windows does TAGRA run on?
TAGRA runs on Windows 10 and Windows 11. It is a desktop application — it installs on the computer, not in a browser, and works offline once installed.
Why do I need to install Firebird and Desktop Runtime?
Firebird is the database that stores your tachograph data on your own computer, and Microsoft Desktop Runtime is the component the application itself runs on. Both are installed automatically as part of the TAGRA setup — you do not have to download them separately. If you already have them on the machine, the installer skips that step.
Can I install TAGRA on more than one computer?
Yes. The licence allows installation on several computers within one company. The database can be shared over the local network, so several people work with the same data instead of keeping separate copies.
Where do I find my licence key?
The key is issued after purchase and is entered directly in the licence menu inside the software. During the 30-day trial no key is needed — the full software runs unrestricted.
Does installing TAGRA require administrator rights?
Yes. The installation writes to Program Files and registers the database service, so the account performing the installation needs administrator rights on the computer. Everyday use afterwards does not.
I am stuck during installation — who can help?
Our technical support team helps directly. Write to helpdesk@tagra.app and describe which of the installation steps the problem appears in — a screenshot of the error speeds things up considerably.
