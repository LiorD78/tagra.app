GNSS fehlt 83: kein Positionssignal — was tun

Truck Data TechnologyAktualisiert September 20263 Min. Lesezeit

Code 83 bedeutet: Der Tachograph hat seit drei Stunden kumulierter Lenkzeit keine GNSS-Positionsdaten erhalten. Der Empfänger selbst wird nicht als defekt gemeldet — er bekommt lediglich kein Signal. Bestätigen Sie die Meldung; bei wiederholtem Auftreten prüft die Werkstatt Empfang und Antenne.

Schweregrad
Mittel

Bestätigen erforderlich, keine Fahrtunterbrechung nötig.

Betroffen
GNSS-Empfang

Kein Gerätedefekt — der Empfänger empfängt lediglich kein Signal.

VDO Anzeige
083

DTC 002C80 beim Stoneridge SE5000 — GNSS-Empfang und Antenne prüfen.

Was es bedeutet

Was dieser Code bedeutet

Code 83, GNSS fehlt, tritt auf, wenn der GNSS-Empfänger des Tachographen seit drei Stunden kumulierter Lenkzeit keine Positionsdaten erhalten hat. Der Empfänger selbst wird dabei nicht als defekt gemeldet — er empfängt schlicht kein Signal. Manche Fahrer suchen auch nach „GNSS-Fehler 83“ statt „GNSS fehlt 83“ — gemeint ist dieselbe Meldung.

Laut Handbuch stuft VDO diese Störung als mittlere Priorität ein. Auf einem Stoneridge SE5000 wird derselbe Zustand im Werkstattdiagnosewerkzeug als DTC 002C80 geführt.

Nicht mit Code 82 verwechseln

Code 83 bedeutet, dass das Signal fehlt — der Empfänger funktioniert, bekommt aber keine Positionsfixierung. Code 82, interne GNSS-Störung, bedeutet dagegen, dass der Empfänger oder seine Antenne selbst defekt ist. Die Abhilfe ist bei beiden unterschiedlich.

Was jetzt zu tun ist

Was jetzt zu tun ist

  1. Meldung am Display bestätigen.
  2. Bei einem Stoneridge SE5000 (DTC 002C80): GNSS-Empfang prüfen und nach Hindernissen suchen — eine verschmutzte, beschädigte oder abgeschirmte Antenne, oder ein Fahrzeug, das an einem Ort ohne freie Sicht zum Himmel geparkt ist (Tiefgarage, dichte Innenstadtbebauung).
  3. Bei wiederholtem Auftreten am selben Fahrzeug eine autorisierte Fachwerkstatt konsultieren.

Was Sie nicht tun sollten

Was Sie nicht tun sollten

  • Nicht davon ausgehen, dass der Empfänger defekt ist — das wäre Code 82.
  • Nicht mit Code 82 (interne GNSS-Störung) oder Code 96 (GNSS-Anomalie) verwechseln.
  • Wiederholtes Auftreten am selben Fahrzeug nicht ignorieren — das deutet auf ein dauerhaftes Antennen- oder Empfangsproblem hin.
  • Nicht selbst an GNSS-Antenne oder Verkabelung hantieren.
Warum es passiert

Warum es passiert

Code 83 wird ausschließlich durch das Fehlen einer Positionsfixierung ausgelöst — nach drei Stunden kumulierter Lenkzeit ohne GNSS-Daten gibt der Tachograph die Meldung aus. Anders als bei Code 82 wird dabei nichts im Gerät selbst als defekt gemeldet — der Empfänger hat schlicht kein Signal, mit dem er arbeiten kann.

Auf dem Stoneridge SE5000 wird derselbe Zustand als DTC 002C80 geführt; empfohlen werden die Prüfung des GNSS-Empfangs selbst und alles, was das Signal abschirmen könnte.

Dürfen Sie weiterfahren?

Dürfen Sie weiterfahren?

Ja, grundsätzlich schon. Das Handbuch stuft Code 83 als Störung mit mittlerer Priorität ein, und die einzige verlangte Maßnahme ist, die Meldung zu bestätigen — es gibt keine Pflicht, die Fahrt zu unterbrechen. Formal gilt gleichwohl die Reparaturpflicht nach Artikel 37 der Verordnung 165/2014: Werkstattbesuch, sobald die Umstände es zulassen, spätestens innerhalb einer Woche nach Feststellung der Störung. Wiederholt sich die Meldung am selben Fahrzeug, deutet das auf ein dauerhaftes Antennen- oder Empfangsproblem hin, das eine Werkstattkontrolle rechtfertigt.

Folgen für das Unternehmen

Folgen für das Unternehmen

Die fehlende Positionsangabe wird im Massenspeicher der Fahrzeugeinheit und auf der Fahrerkarte gespeichert und ist bei jeder späteren Auswertung oder Kontrolle sichtbar. Weil das Positionsmodul der Aufzeichnung betroffen ist, kann sie bei einer BAG-Kontrolle Rückfragen zu fehlenden oder lückenhaften Positionsdaten auslösen — vor allem, wenn sie wiederholt am selben Fahrzeug auftritt.

Bleibt die Ursache ungeklärt, drohen bei einer Straßenkontrolle Beanstandungen wegen Verstoßes gegen die Reparaturpflicht nach Artikel 37 — unabhängig von der tatsächlichen Ursache. Ein dokumentierter Werkstattbesuch mit Prüfbericht ist deshalb die wichtigste Absicherung für das Unternehmen, wenn die Meldung wiederkehrt.

Fragen & Antworten

Häufig gestellte Fragen

Ist Code 83 dasselbe wie eine interne GNSS-Störung (Code 82)?

Nein. Code 83 bedeutet, dass das Signal fehlt — der Empfänger funktioniert, bekommt aber keine Positionsfixierung. Code 82, interne GNSS-Störung, bedeutet dagegen, dass der Empfänger oder seine Antenne selbst defekt ist.

Darf ich mit GNSS fehlt 83 weiterfahren?

Ja. Das Handbuch stuft Code 83 als Störung mit mittlerer Priorität ein, und die einzige verlangte Maßnahme ist, die Meldung zu bestätigen. Wiederholt sie sich am selben Fahrzeug, ist eine Werkstattkontrolle sinnvoll; formal gilt die Reparaturpflicht nach Artikel 37, spätestens innerhalb einer Woche.

Was bedeutet DTC 002C80 auf dem Stoneridge SE5000?

DTC 002C80 ist der Werkstattcode des Stoneridge SE5000 für ein fehlendes GNSS-Signal. Empfohlen wird, den GNSS-Empfang und mögliche Abschirmungen der Antenne zu prüfen — etwa eine verschmutzte, beschädigte Antenne oder einen Standort ohne freie Sicht zum Himmel.

Was verursacht ein fehlendes GNSS-Signal am Tachographen?

Der Tachograph hat seit drei Stunden kumulierter Lenkzeit keine gültige Positionsangabe erhalten. Häufige Ursachen sind eine verschmutzte, beschädigte oder abgeschirmte Antenne oder ein Fahrzeug, das lange an einem Ort ohne freie Sicht zum Himmel steht — etwa in einer Tiefgarage oder zwischen hohen Gebäuden.
