Häufige Fragen zur Installation
Unter welchen Windows-Versionen läuft TAGRA?
TAGRA läuft unter Windows 10 und Windows 11. Es handelt sich um eine Desktopanwendung – sie wird auf dem Computer und nicht in einem Browser installiert und funktioniert nach der Installation offline.
Warum muss ich Firebird und Desktop Runtime installieren?
Firebird ist die Datenbank, in der Ihre Tachograph-Daten auf Ihrem eigenen Computer gespeichert werden. Microsoft Desktop Runtime ist die Komponente, auf der die Anwendung selbst läuft. Beide Komponenten werden automatisch im Rahmen der TAGRA-Installation installiert – Sie müssen sie nicht separat herunterladen. Wenn sie bereits auf dem Computer vorhanden sind, überspringt das Installationsprogramm diesen Schritt.
Kann ich TAGRA auf mehreren Computern installieren?
Ja. Die Lizenz erlaubt die Installation auf mehreren Computern innerhalb eines Unternehmens. Die Datenbank kann über das lokale Netzwerk gemeinsam genutzt werden, sodass mehrere Personen mit denselben Daten arbeiten können, anstatt separate Kopien zu führen.
Wo finde ich meinen Lizenzschlüssel?
Der Schlüssel wird nach dem Kauf ausgestellt und direkt im Lizenzmenü der Software eingegeben. Während des 30-tägigen Testzeitraums ist kein Schlüssel erforderlich – die vollständige Software läuft uneingeschränkt.
Sind für die Installation von TAGRA Administratorrechte erforderlich?
Ja. Bei der Installation werden Dateien in „Program Files“ geschrieben und der Datenbankdienst registriert. Daher benötigt das Konto, mit dem die Installation durchgeführt wird, Administratorrechte auf dem Computer. Für die anschließende tägliche Nutzung sind diese nicht erforderlich.
Ich komme bei der Installation nicht weiter – wer kann mir helfen?
Unser technischer Support hilft Ihnen direkt. Schreiben Sie an helpdesk@tagra.app und beschreiben Sie, bei welchem Installationsschritt das Problem auftritt – ein Screenshot des Fehlers beschleunigt die Bearbeitung erheblich.
