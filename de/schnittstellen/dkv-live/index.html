direkt in TAGRA

Nutzen Sie bereits DKV LIVE® für die Fernauslesung von Tachographendaten? TAGRA importiert die Daten automatisch — keine manuellen Dateiübertragungen, keine zusätzlichen Klicks.

Testen Sie TAGRA 30 Tage kostenlos

Windows · Kostenlose 30-Tage-Testversion · Bereit für Transporter ab Juli 2026

Ihre Vorteile

Keine manuelle
Dateiübertragungen

DKV LIVE® ist ein Telematikdienst, der Tachographen- und Fahrerkartendaten aus Ihren Fahrzeugen über das Mobilfunknetz abruft und sie auf einem sicheren SFTP-Server speichert.

TAGRA verbindet sich mit diesem Server und importiert die Daten automatisch, zu dem von Ihnen gewählten Zeitpunkt — von einmal täglich bis alle paar Stunden.

Das Ergebnis: Daten von jedem Fahrzeug in Ihrem Fuhrpark fließen direkt in TAGRA, bereit für die Auswertung, Verstoßberichte und Archivierung. Keine Download-Keys, kein Herumlaufen auf dem Hof, keine verpassten Fristen.

DKV LIVE® Telematik + TAGRA = volle Automation

Wenn Sie bereits für DKV LIVE® Telematik bezahlen, benötigen Sie keine zusätzliche Hardware, um Tachographendaten in TAGRA zu erhalten. Geben Sie einfach Ihre DKV Zugangsdaten im TAGRA Datenimport Bildschirm ein und Sie sind fertig.

Einrichtungsanleitung

Schritt für Schritt

Die Einrichtung des DKV LIVE® Imports in TAGRA dauert etwa zwei Minuten. Sie müssen dies nur einmal tun — danach ruft TAGRA die Daten automatisch ab.

01
Datenimport öffnen

Klicken Sie im Hauptfenster von TAGRA auf Datenimpor(Datenimport) im linken Menü. Hier richten Sie die Verbindung zwischen DKV LIVE® und TAGRA ein.

02
Neuen Import hinzufügen

Klicken Sie im linken Bereich des Bildschirms „Datenimport“ auf Import hinzufügen. Ein Konfigurationsfenster öffnet sich.

03
Verbindung konfigurieren

Füllen Sie das Konfigurationsfenster aus:

  • Importname — eine beliebige Bezeichnung (z.B. „DKV“)
  • Ordner — geben Sie/(einen einzelnen Schrägstrich)
  • Ausführungsintervall — wie oft TAGRA Daten abrufen soll (empfohlen:1dfür täglich)
  • SFTP Server — sftp.styletronic.eu
  • Port — 22
  • Benutzername und Passwort — Ihre DKV LIVE® Zugangsdaten

Bestätigen Sie mit OK.

04
Den ersten Import ausführen

Klicken Sie auf Ihre neue Verbindung (sie wird blau hervorgehoben) und drücken Sie Import ausführen. TAGRA ruft die neuesten Tachograph- und Fahrerkartendateien sofort vom DKV-Server ab. Wenn der Vorgang abgeschlossen ist, wechseln Sie zurück zum Hauptbildschirm und starten Sie Ihre Auswertung.

Automatisch oder manuell?

Einmal einrichten,
nicht mehr daran denken

Das Ausführungsintervall Feld entscheidet, wie oft TAGRA Daten von DKV LIVE® abruft:

  • 1d— einmal täglich (empfohlen)
  • 12h— alle 12 Stunden
  • 6h, 3h, 1h— häufiger
  • 0s— nur manuell (Sie klicken auf Import ausführen selbst)

Wir empfehlen mindestens täglich, damit Ihre Daten aktuell bleiben und die gesetzlichen 28- und 90-Tage-Auslesefristen immer eingehalten werden.

Warum es wichtig ist 28 und 90 Tage sind gesetzliche Fristen

EU-Vorschriften verlangen, dass Fahrerkarte-Daten mindestens alle 28 Tage und Tachograph-Daten mindestens alle 90 Tage.

Mit DKV LIVE® + TAGRA, das täglich läuft, werden diese Fristen automatisch eingehalten. Sie haben außerdem eine saubere, archivierte Dokumentation für jede Kontrolle.

Häufig gestellte Fragen

FAQ

Welche TAGRA-Versionen unterstützen DKV LIVE®?
Alle aktuellen TAGRA-Versionen — TAGRA 1, 2, 4, 6 und MAX — unterstützen den DKV LIVE®-Import ab Version 345. Die Versionsnummer wird am unteren Rand des TAGRA-Fensters angezeigt. Wenn Sie eine ältere Version haben, aktualisieren Sie diese über den In-App-Updater — Updates sind in Ihrer jährlichen Lizenz enthalten.
Woher bekomme ich meine DKV LIVE®-Zugangsdaten?
Von Ihrem DKV Mobility Account Manager oder Vertriebsmitarbeiter. TAGRA benötigt einen gültigen SFTP-Benutzernamen und ein Passwort für den DKV LIVE®-Server — die gleichen, die Sie auch für den direkten Zugriff auf den Dienst verwenden würden. Wir übernehmen keine DKV-Konto-Bereitstellung.
Wie oft sollte TAGRA Daten von DKV LIVE® abrufen?
Wir empfehlen mindestens einmal täglich(Intervall1d). Das hält Ihre Daten aktuell und stellt sicher, dass Sie die gesetzlichen 28-Tages- und 90-Tages-Auslesefristen gut einhalten. Sie können es auch auf alle paar Stunden einstellen, wenn Sie eine nahezu Echtzeit-Auswertung bevorzugen — beides funktioniert einwandfrei.
Was passiert, wenn der Import fehlschlägt oder eine Fehlermeldung ausgibt?
Überprüfen Sie zunächst den SFTP-Server (sftp.styletronic.eu), den Port (22) und Ihre Zugangsdaten. Wenn diese korrekt sind und der Import weiterhin fehlschlägt, kontaktieren Sie uns per E-Mail unter helpdesk@tagra.app. Die Fehlermeldung in der Importliste von TAGRA hilft uns, das Problem schnell zu diagnostizieren.
Benötige ich DKV LIVE® für die Fernauslesung von Tachographen?
Nein. DKV LIVE® ist eine von mehreren Möglichkeiten, Tachograph-Daten in TAGRA zu importieren — es ist eine großartige Option, wenn Sie bereits den Telematikdienst von DKV nutzen. Falls nicht, akzeptiert TAGRA auch standardmäßige.DDD, .C1Bund.V1BDateien von jedem anderen Tachograph-Auslesewerkzeug. Kontaktieren Sie uns, wenn Sie eine Empfehlung wünschen.
Ist TAGRA offiziell Partner von DKV?
TAGRA importiert Daten vom DKV LIVE® SFTP-Dienst mithilfe Ihrer eigenen DKV-Anmeldedaten. Dies ist eine technische Interoperabilitätsfunktion, keine formelle Partnerschaft oder Empfehlung. DKV LIVE® ist eine Marke von DKV Mobility.
Ist der DKV LIVE® Import in meiner TAGRA-Lizenz enthalten?
Ja. Die Datenimportfunktion (einschließlich DKV LIVE® Konnektivität) ist Bestandteil jeder aktuellen TAGRA-Lizenz ohne zusätzliche Kosten. Sie zahlen lediglich Ihre normale TAGRA-Lizenzgebühr und Ihr normales DKV LIVE® Abonnement – nichts weiter.
