Printing not possible — tachograph error code 36

Truck Data TechnologyUpdated September 20263 min read

Code 36 means your tachograph can't produce a printout right now — usually because the paper has run out, the printer drawer isn't fully closed, the print head has overheated, or the supply voltage is too low.

Severity
Medium

Confirm, retry the print, workshop if it persists.

Affected part
Printer module

Paper feed, drawer switch, print head or power supply.

Keep driving?
Yes

But resolve it before a roadside check — printouts can be requested on demand.

What it means

What this code means

Every digital tachograph must be able to print a record on request — for a roadside check, a workshop download, or your own records. Code 36, printing not possible, means that function is currently blocked.

The manual lists four practical causes behind this message: no paper loaded, the printer drawer left open, an overheated print head, or supply voltage outside the required range.

What to do now

What to do now

The manual's guidance for code 36:

  1. Check the paper — load a fresh roll if it's empty.
  2. Close the printer drawer fully until it latches.
  3. Let the print head cool down if it's been printing continuously, then retry.
  4. Confirm the message and repeat the print — cycling the ignition can help if the fault was a voltage dip.
  5. If printing still fails, consult an approved workshop.

Why it happens

Why it happens

According to the manual, code 36 has four possible causes:

  • Paper roll empty or missing.
  • Printer drawer not fully closed or latched.
  • Print head overheated from continuous printing.
  • Supply voltage too low or unstable for the printer to operate.
Severity

Can you keep driving?

Yes — code 36 does not affect the recording of your driving time, breaks or rest. The manual classifies it as Medium severity because of what it stops you doing, not because it threatens the tachograph's data.

Regulation 165/2014 requires you to be able to produce a printout on request at a roadside check, for the current day and the previous 28 days. If code 36 isn't resolved before you're stopped, you may not be able to comply with that request — carry a spare paper roll at all times, and treat a persistent code 36 as something to fix before your next check, not after.

Questions & answers

Frequently asked questions

What causes "printing not possible" (code 36)?

The manual lists four practical causes: no paper loaded, the printer drawer left open, an overheated print head, or supply voltage outside the required range. Checking these in order resolves most cases without a workshop visit.

Can I keep driving with code 36?

Yes. Code 36 does not affect the recording of your driving time, breaks or rest. But because you may need to produce a printout on request at a roadside check, resolve the fault as soon as possible rather than waiting.

Is it a legal problem if I can't print at a roadside check?

Regulation 165/2014 requires you to be able to produce a printout on request for the current day and the previous 28 days. If a technical fault prevents that, carrying a spare paper roll and fixing the underlying cause promptly is the best protection — an unresolved, recurring fault is harder to explain than a one-off.

What if code 36 keeps coming back after I've checked the paper and drawer?

A recurring fault after ruling out paper and drawer issues usually points to the print head or the printer's power supply. Consult an approved workshop — the manual lists an overheated head or low supply voltage as the remaining causes.
