GNSS is missing — tachograph error code 83

Truck Data TechnologyUpdated September 20263 min read

Code 83 means your tachograph has had no position data for three hours of cumulative driving time.

Severity
Medium

Requires acknowledgement of the message.

Trigger
3 hours

No GNSS position data over three hours of cumulative driving.

Stoneridge DTC
002C80

Check GNSS reception and look for obstructions to the signal.

What it means

What this code means

Code 83, GNSS is missing, appears when the tachograph's GNSS receiver has not received any position data for three hours of cumulative driving time. The receiver itself is not reported as faulty — it simply isn't getting a signal.

According to the manual, the severity of this fault is Medium. On a Stoneridge SE5000, the same fault is logged in the workshop diagnostic tool as DTC 002C80.

Don't confuse this with code 82

Code 83 means the signal is missing — the receiver is working but isn't getting a position fix. Internal GNSS fault (code 82) means the receiver or its antenna is itself faulty. The fix is different for each.

What to do now

What to do now

The manual gives one instruction for code 83:

  1. Acknowledge the message on the tachograph display.

If your unit is a Stoneridge SE5000 (DTC 002C80): check the GNSS reception and look for anything obstructing the signal — a dirty, damaged or shielded antenna, or the vehicle parked somewhere the antenna can't see the sky, are the usual causes.

Why it happens

Why it happens

Code 83 is triggered purely by the absence of a position fix — after three hours of cumulative driving with no GNSS data, the tachograph raises the message. On a Stoneridge SE5000 (DTC 002C80), the recommended checks are the GNSS reception itself and anything that might be obstructing the signal.

This is distinct from code 82: with code 83, nothing is reported as broken inside the unit — the receiver simply has no signal to work with.

Severity

Can you keep driving?

The manual classifies code 83 as Medium severity, and the only instruction given is to acknowledge the message — there is no requirement to stop.

If you drive a Stoneridge SE5000, check the GNSS reception and look for obstructions to the antenna once you have the chance. If the message keeps recurring on the same vehicle, that points to a persistent antenna or positioning problem worth raising with your workshop.

Questions & answers

Frequently asked questions

What triggers "GNSS is missing" (code 83)?

The tachograph has had no GNSS position data for three hours of cumulative driving time. The receiver itself is not reported as faulty — it simply hasn't received a signal.

What is the difference between code 83 and code 82?

Code 83 means the signal is missing — the receiver is working but isn't getting a position fix. Code 82, internal GNSS fault, means the receiver or its antenna is itself faulty.

Can I keep driving with code 83?

Yes. The manual classifies it as Medium severity and asks only that you acknowledge the message. There is no requirement to stop.

What does DTC 002C80 mean on a Stoneridge SE5000?

DTC 002C80 is the Stoneridge SE5000 workshop code for a missing GNSS signal. The recommended checks are the GNSS reception itself and anything that might be obstructing the antenna's view of the sky.
