GNSS manquant — code d'anomalie du tachygraphe 83

Truck Data TechnologyMis à jour en septembre 2026Lecture de 3 min

Le code 83 signifie que votre tachygraphe n’a reçu aucune donnée de position pendant trois heures de temps de conduite cumulé.

Gravité
Moyenne

Acquittement du message requis.

Déclencheur
3 heures

DTC Stoneridge
002C80

Signification

Ce que signifie ce code

Le code 83, GNSS manquant, apparaît lorsque le récepteur GNSS du tachygraphe n'a reçu aucune donnée de position pendant trois heures de temps de conduite cumulé. Le récepteur lui-même n'est pas signalé comme présentant une anomalie — il ne reçoit simplement aucun signal.

Selon le manuel, la gravité de cette anomalie est Moyenne. Sur un Stoneridge SE5000, la même anomalie est enregistrée dans l’outil de diagnostic d’atelier sous le code DTC 002C80.

Ne confondez pas ce code avec le code 82

Le code 83 signifie que le signal est absent — le récepteur fonctionne, mais n'obtient pas de position. Anomalie interne GNSS (code 82) signifie que le récepteur ou son antenne présente lui-même une anomalie. La solution diffère dans chaque cas.

Que faire maintenant

Que faire maintenant

Le manuel donne une seule instruction pour le code 83 :

  1. Acquittez le message sur l’écran du tachygraphe.

Si votre unité est un Stoneridge SE5000 (DTC 002C80) : vérifiez la réception GNSS et recherchez tout ce qui pourrait obstruer le signal — une antenne sale, endommagée ou protégée, ou un véhicule stationné à un endroit où l’antenne ne peut pas voir le ciel sont les causes habituelles.

Votre tachygraphe enregistre cette anomalie — TAGRA la lit

TAGRA ne rétablit pas un signal GNSS perdu — cela dépend de l'antenne et de l'endroit où le véhicule est stationné. Mais une fois le code 83 enregistré dans la mémoire du tachygraphe et sur votre carte de conducteur, TAGRA le retrouve dans vos données téléchargées, l'évalue et le documente — exactement ce dont vous avez besoin lors d'un contrôle routier et lorsque vous adressez une demande à l'atelier.

Pourquoi cela se produit

Pourquoi cela se produit

Le code 83 est déclenché uniquement par l'absence de position — après trois heures de conduite cumulée sans données GNSS, le tachygraphe affiche le message. Sur un Stoneridge SE5000 (DTC 002C80), les vérifications recommandées concernent la réception GNSS elle-même et tout élément susceptible d'obstruer le signal.

Cela se distingue du code 82 : avec le code 83, aucune anomalie n'est signalée à l'intérieur de l'unité — le récepteur n'a simplement aucun signal à exploiter.

Gravité

Pouvez-vous continuer à conduire ?

Le manuel classe le code 83 comme gravité moyenne, et la seule instruction donnée consiste à acquitter le message — il n'est pas nécessaire de s'arrêter.

Si vous conduisez un Stoneridge SE5000, vérifiez la réception GNSS et recherchez les obstructions de l'antenne dès que vous en avez la possibilité. Si le message réapparaît régulièrement sur le même véhicule, cela indique un problème persistant d'antenne ou de positionnement qu'il convient de signaler à votre atelier.

Questions & réponses

Questions fréquemment posées

Qu'est-ce qui déclenche « GNSS is missing » (code 83) ?

Le tachygraphe n'a reçu aucune donnée de position GNSS pendant trois heures de temps de conduite cumulé. Le récepteur lui-même n'est pas signalé comme présentant une anomalie — il n'a simplement reçu aucun signal.

Quelle est la différence entre les codes 83 et 82 ?

Le code 83 signifie que le signal est absent — le récepteur fonctionne, mais n'obtient pas de position. Le code 82, anomalie interne GNSS, signifie que le récepteur ou son antenne présente lui-même une anomalie.

Puis-je continuer à conduire avec le code 83 ?

Oui. Le manuel le classe au niveau de gravité moyen et demande seulement que vous acquittiez le message. Il n'est pas nécessaire de s'arrêter.

Que signifie DTC 002C80 sur un Stoneridge SE5000 ?

DTC 002C80 est le code atelier du Stoneridge SE5000 correspondant à une absence de signal GNSS. Les vérifications recommandées concernent la réception GNSS elle-même et tout élément susceptible d'obstruer la vue du ciel par l'antenne.
