Anomalie du capteur de mouvement 21 : ce que cela signifie et ce que vous devez faire

Truck Data TechnologyMis à jour en septembre 20263 min de lecture

Le code 21 signifie que le tachygraphe a perdu la communication correcte avec le capteur de mouvement — le capteur de mouvement monté sur la boîte de vitesses. Selon le manuel, la cause peut être une interruption de l'alimentation électrique du capteur, un câblage endommagé, l'absence d'impulsions, une discordance du compteur ou un remplacement non autorisé du capteur. Vous ne pouvez pas réparer ce problème vous-même — une inspection dans un atelier agréé est requise (détenant une autorisation du président de GUM).

Ce que signifie ce code

Ce que signifie ce code

Capteur de mouvement, c'est-à-dire le capteur de mouvement, est monté sur la boîte de vitesses et transmet les impulsions de vitesse à l'unité embarquée (VU) du tachygraphe. Le code 21, anomalie du capteur de mouvement, signifie que cette communication est interrompue — l'unité embarquée ne reçoit pas les données de mouvement correctes du capteur de mouvement.

Ne le confondez pas avec le code 16

Le code 16, une anomalie du capteur à la suite d'un autotest, signifie que le capteur lui-même a signalé un problème interne au cours de ses propres diagnostics. Le code 21, en revanche, concerne la communication entre le capteur et l'unité embarquée — câblage, alimentation électrique ou appairage — et n'indique pas nécessairement une anomalie du capteur lui-même.

Ce que vous devez faire maintenant

Ce que vous devez faire maintenant

  1. Le message doit être confirmé, en appuyant sur OK à l'écran.
  2. Rendez-vous dans un lieu sûr pour vous arrêter.
  3. Vous devez établir un ticket imprimé du tachygraphe pour la journée en cours.
  4. Effectuer des saisies manuelles toutes les activités ultérieures au verso de ce ticket imprimé — jusqu’à la réparation de l’anomalie.
  5. Informer le gestionnaire de flotte et vous rendre dans un atelier agréé dès que possible.

Continuer à conduire sans effectuer d'enregistrements manuels alors que vous avez déjà connaissance de l'anomalie du capteur de mouvement constitue une infraction grave dans tous les pays de l'UE.

Ce qu’il ne faut pas faire

Ce qu’il ne faut pas faire

  • N'essayez pas de le remplacer ou de le réparer vous-même du capteur de mouvement — une interférence non autorisée est l’une des causes possibles de ce code et peut être considérée comme une tentative de manipulation frauduleuse lors d’un contrôle.
  • Ne le confondez pas avec le code 16 (anomalie du capteur de mouvement après l'autotest) — il s'agit d'un problème différent, situé dans le capteur de mouvement lui-même.
  • Ne poursuivez pas votre conduite sans effectuer les saisies manuelles — contrairement à une anomalie de faible priorité, le code 21 nécessite une intervention immédiate.
  • N'ignorez pas un message récurrent sur le même véhicule — cela indique un problème persistant au niveau du capteur ou du câblage.
Pourquoi apparaît-il ?

Pourquoi apparaît-il ?

Selon le manuel, la cause du code 21 peut être :

  • coupure de l’alimentation électrique du capteur de mouvement;
  • câblage endommagé ou desserré entre le capteur de mouvement et l’unité embarquée ;
  • impulsions manquantes du capteur de mouvement ;
  • discordance du compteur kilométrique — discordance entre les données du capteur de mouvement et une autre source de données de mouvement; ou
  • remplacement non autorisé du capteur — l’appariement d’un nouveau capteur de mouvement avec l’unité embarquée ne correspond pas.

Par exemple EventFaultType 0x09 (« erreur des données de mouvement ») conformément à l'annexe I C du règlement (UE) 2016/799, le code 21 appartient au même groupe que les codes 020, 022 et 087 — l'anomalie est enregistrée dans la mémoire de masse de l'unité embarquée et sur la carte de conducteur.

Pouvez-vous continuer à conduire ?

Pouvez-vous continuer à conduire ?

En bref : oui, mais uniquement pour rejoindre le lieu d'arrêt sûr le plus proche. Le code 21 a haute priorité, car le capteur de mouvement est la source des données relatives à la vitesse et à la distance parcourue ; son anomalie affecte donc la fiabilité de l'ensemble des enregistrements du temps de conduite. Dès que vous avez connaissance de l'anomalie, vous devez continuer à conduire en utilisant uniquement les enregistrements manuels des activités au verso du ticket imprimé du jour — jusqu'à la réparation du véhicule dans un atelier agréé.

Formellement, l'article 37 du règlement 165/2014 s'applique : la réparation doit être effectuée dès que les circonstances le permettent et, si le véhicule ne peut pas regagner sa base dans un délai d'une semaine à compter de la détection de l'anomalie, la réparation doit être effectuée en cours de route.

Conséquences pour l'entreprise

Conséquences pour l'entreprise

Le capteur de mouvement fournit des données sur les mouvements du véhicule, sur lesquelles repose l’ensemble de l’enregistrement du temps de conduite, des pauses et des temps de repos. Les autorités de contrôle prennent très au sérieux une anomalie du capteur de mouvement — il s’agit de l’un des composants les plus fréquemment contrôlés lorsqu’une manipulation frauduleuse du tachygraphe est suspectée, car le remplacement non autorisé du capteur constitue l’une des causes possibles du code 21.

Si le conducteur continue à conduire sans effectuer les enregistrements manuels requis, ou si l'entreprise ne peut pas documenter la réparation dans un délai raisonnable, le contrôle routier peut entraîner la constatation d'une infraction pour non-respect de l'obligation de réparation prévue à l'article 37 — et, si une manipulation frauduleuse est suspectée, également l'ouverture d'autres procédures d'enquête.

Questions et réponses

Questions fréquemment posées

Le message « motion sensor fault » s'affiche sur l'écran du VDO — pouvez-vous continuer à conduire ?

En bref, oui — pour rejoindre un lieu d'arrêt sûr. Vous devez ensuite : (1) appuyer sur OK pour confirmer, (2) imprimer un ticket imprimé du tachygraphe pour le jour concerné, (3) inscrire manuellement toutes les activités ultérieures au dos de ce ticket imprimé, (4) informer le gestionnaire de flotte et (5) rejoindre un atelier agréé dès que les circonstances le permettent. Continuer à conduire sans effectuer d'enregistrements manuscrits après avoir pris connaissance de l'anomalie constitue une infraction grave dans tous les pays de l'UE.

Quelles sont les causes du code 21 ?

Selon le manuel, la cause peut être une interruption de l'alimentation électrique du capteur de mouvement, un câblage endommagé ou desserré entre le capteur et l'unité embarquée, l'absence d'impulsions du capteur, une discordance du compteur ou un remplacement non autorisé du capteur.

Quelle est la différence entre le code 21 et le code 16 ?

Le code 16 signifie que le capteur lui-même a signalé un problème interne après son propre autotest. Le code 21 concerne la communication entre le capteur et l'unité embarquée — câblage, alimentation électrique ou appairage — et n'indique pas nécessairement une anomalie du capteur lui-même.

Un remplacement non autorisé du capteur de mouvement peut-il déclencher le code 21 ?

Oui. Si le nouveau capteur de mouvement n’est pas correctement associé à l’unité embarquée dans un atelier agréé, le tachygraphe signalera une anomalie du capteur de mouvement. C’est l’une des raisons pour lesquelles le code 21 est hautement prioritaire et nécessite une inspection dans un atelier, plutôt que toute tentative de réparation de votre part.
