Anomalie de carte 41 — Code d'erreur 41 du tachygraphe

Truck Data TechnologyMis à jour en septembre 20263 min de lecture

Le code 41 signifie que votre tachygraphe ne peut pas lire ou écrire de manière fiable sur la carte de conducteur insérée dans le lecteur 1 — il s'agit presque toujours d'un problème de contact, et non d'une carte défectueuse.

Moyenne

Composant concerné
Carte de conducteur / contacts du lecteur de carte

Les contacts métalliques par lesquels le tachygraphe échange des données avec votre carte.

DTC Stoneridge
041

Erreur de communication avec la carte, lecteur 1. Pour le lecteur 2 (second conducteur), le code enregistré est 059.

Signification

Ce que signifie ce code

Les tachygraphes numériques lisent et écrivent en continu sur la carte de conducteur insérée dans le lecteur 1 — les activités, événements et anomalies y sont enregistrés pendant le service. Le code 41, anomalie de carte, signifie qu'une tentative de lecture ou d'écriture sur la carte a échoué.

Le manuel d'utilisation du VDO DTCO 4.1 décrit ce problème sous la forme x1 Anomalie de carte xx : « Une anomalie de communication s'est produite lors de la lecture ou de l'écriture sur la carte de conducteur, généralement à cause de contacts encrassés. Certaines données du conducteur n'ont peut-être pas été écrites. » Le manuel classe sa gravité comme moyenne.

Sur un Stoneridge SE5000, le code de diagnostic d'atelier correspondant est 041 — Erreur de communication avec la carte, lecteur 1 (carte de conducteur). Si le même problème concerne la carte du second conducteur dans le lecteur 2, il est enregistré sous le code 059.

À ne pas confondre avec les codes 50 ou 44

L'anomalie de carte 41 signifie que le tachygraphe a eu des difficultés à communiquer avec une carte toujours insérée — le nettoyage des contacts résout généralement le problème. L'erreur de carte 50 est plus grave : la carte est refusée et éjectée. La carte non fermée 44 correspond à un autre problème : une session précédente de la carte n'a pas été clôturée correctement, sans qu'il s'agisse d'un problème de communication avec la carte actuelle.

Si la même anomalie se produit chez plusieurs conducteurs ou sur plusieurs véhicules, un logiciel de lecture de carte de conducteur vous permet de consulter l'erreur pour toute la flotte en un seul endroit.

Que faire maintenant

Que faire maintenant

  1. Acquittez le message sur l'écran du tachygraphe.
  2. Nettoyez les contacts de la carte avec un chiffon sec et réinsérez la carte.
  3. Si l'anomalie se reproduit, la carte devrait être remplacée.

Sur un Stoneridge SE5000 : le même événement est enregistré sous le code DTC 041 (lecteur 1, conducteur) ou 059 (lecteur 2, second conducteur). La solution est identique dans les deux cas : nettoyez les contacts de la carte et du lecteur de carte, puis réinsérez la carte.

Pourquoi cela se produit

Pourquoi cela se produit

Selon le manuel, l'anomalie de carte 41 est généralement causée par :

  • des contacts encrassés ou oxydés sur la carte de conducteur elle-même ;
  • des contacts encrassés ou usés dans le lecteur de carte ; ou
  • une carte mal insérée ou retirée pendant une opération de lecture ou d'écriture.

L'anomalie interrompant une opération de lecture ou d'écriture, certaines données du conducteur pour ce service n'ont peut-être pas été enregistrées sur la carte — une raison de vérifier les activités enregistrées sur votre carte à la fin du service si l'anomalie s'est produite.

Gravité

Pouvez-vous continuer à conduire ?

Le manuel classe l'anomalie de carte 41 comme une anomalie de priorité moyenne — elle n'impose pas un arrêt immédiat. Acquittez le message, nettoyez les contacts, réinsérez la carte et poursuivez votre service.

La tentative de lecture ou d'écriture ayant échoué, des données de ce service peuvent manquer sur la carte — vérifiez-le à la fin du service. Si l'anomalie se reproduit et que la carte ne peut effectivement plus être lue de manière fiable, vous devez, conformément à l'article 29 du règlement (UE) nº 165/2014, demander une carte de remplacement dans les 7 jours calendaires suivant la survenue du défaut ; jusqu'à réception de la nouvelle carte, l'article 29, paragraphe 5, autorise la conduite sans carte pendant un maximum de 15 jours calendaires, à condition d'effectuer les impressions (tickets) prescrites par l'article 35 au début et à la fin de chaque service (ou plus longtemps si cela est nécessaire pour ramener le véhicule au siège de l'entreprise).

Questions & réponses

Questions fréquentes

Quelle est la différence entre l'anomalie de carte 41 et l'erreur de carte 50 ?

L'anomalie de carte 41 signifie que le tachygraphe et une carte insérée ont rencontré un problème de communication, généralement causé par des contacts encrassés — le nettoyage des contacts et la réinsertion de la carte résolvent généralement le problème. L'erreur de carte 50 est plus grave : le tachygraphe refuse la carte et l'éjecte. Si le nettoyage des contacts n'empêche pas le code 41 de réapparaître, cela indique que la carte elle-même doit être remplacée.

Que signifie le code DTC 041 sur un Stoneridge SE5000 ?

DTC 041 est le code d'atelier du Stoneridge SE5000 correspondant à une erreur de communication avec la carte dans le lecteur 1, celui de la carte de conducteur. La même anomalie dans le lecteur 2, celui de la carte du second conducteur, est enregistrée sous le code DTC 059.

Puis-je continuer à conduire avec l'anomalie de carte 41 ?

Oui — le manuel la classe comme une anomalie de priorité moyenne. Acquittez le message, nettoyez les contacts et poursuivez votre trajet. La tentative de lecture ou d'écriture ayant échoué, vérifiez les données de votre carte à la fin du service ; si l'anomalie se reproduit, demandez une carte de remplacement.

Quelles sont les causes de l'anomalie de carte 41 sur un tachygraphe numérique ?

Selon le manuel, il s'agit généralement de contacts encrassés ou oxydés sur la carte de conducteur elle-même, de contacts encrassés ou usés dans le lecteur de carte, ou d'une carte mal insérée ou retirée pendant une opération de lecture ou d'écriture. Voir aussi Éjection impossible (code 34).
