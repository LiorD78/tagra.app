Anomalie GNSS interne — code d’anomalie 82 du tachygraphe

Truck Data TechnologyMis à jour en septembre 2026Lecture de 3 min

Le code 82 signifie que votre tachygraphe a détecté une anomalie interne affectant son récepteur de positionnement GNSS.

Gravité
Moyenne

Acquittement requis et consultation d’un atelier.

Élément concerné
Récepteur GNSS

Dispositif qui détermine la position du véhicule pour l’enregistrement.

DTC Stoneridge
000C31

Coupez puis rétablissez l’alimentation, effectuez un essai routier, puis faites-le remplacer si l’anomalie persiste.

Signification

Ce que signifie ce code

Les tachygraphes numériques modernes utilisent un Récepteur GNSS pour enregistrer la position du véhicule au début et à la fin d’une période de travail, ainsi qu’à intervalles définis pendant la conduite. Le code 82, anomalie GNSS interne, signifie que le tachygraphe a détecté un problème interne affectant ce récepteur — et non une simple perte de signal.

Selon le manuel, la gravité de cette anomalie est Moyenne. Sur un Stoneridge SE5000, la même anomalie est enregistrée dans l’outil de diagnostic d’atelier sous le code DTC 000C31.

Ne confondez pas ce code avec le code 83

Le code 82 signifie que le récepteur GNSS ou l’antenne elle-même est défectueux. Le code 83, GNSS manquant, signifie que le récepteur fonctionne, mais ne reçoit simplement pas de signal de position. Consultez la comparaison complète sur cette page.

Que faire maintenant

Que faire maintenant

Le manuel donne une instruction pour le code 82 :

  1. Acquittez le message sur l’écran du tachygraphe.
  2. Consultez un atelier agréé.

Si votre unité est un Stoneridge SE5000 : la procédure d’atelier pour le DTC 000C31 consiste à couper puis rétablir l’alimentation du tachygraphe et à effectuer un essai routier. Si l’anomalie persiste, le récepteur doit être remplacé.

Votre tachygraphe enregistre cette anomalie — TAGRA la lit

TAGRA ne répare pas une anomalie GNSS — seul un atelier agréé peut remplacer un récepteur ou une antenne défectueux. Mais une fois le code 82 enregistré dans la mémoire du tachygraphe et sur votre carte de conducteur, TAGRA le retrouve dans vos données téléchargées, l’évalue et le documente — exactement ce dont vous avez besoin lors d’un contrôle routier et pour présenter une demande de garantie à l’atelier.

Pourquoi cela se produit

Pourquoi cela se produit

Selon le manuel, le code 82 peut avoir trois causes :

  • une anomalie interne dans le dispositif GNSS propre au tachygraphe ;
  • un court-circuit sur l’antenne GNSS externe, si elle est installée ; ou
  • l’absence de connexion à l’antenne GNSS externe.

Sur un Stoneridge SE5000 (DTC 000C31), le problème sous-jacent est décrit comme l’arrêt de la transmission des données de position par le récepteur GNSS interne.

Gravité

Pouvez-vous continuer à conduire ?

Le manuel classe le code 82 comme une anomalie de gravité moyenne. Vous devez acquitter le message et consulter un atelier agréé — ce n’est pas une anomalie qui vous oblige à vous arrêter sur place.

Comme elle affecte le récepteur chargé des données de position du tachygraphe, ne la laissez pas se prolonger indéfiniment : prenez rapidement rendez-vous en atelier plutôt que d’attendre que le problème récurrent se résolve de lui-même. Sur une unité Stoneridge, la première étape consiste à couper puis rétablir l’alimentation et à effectuer un essai routier ; si l’anomalie réapparaît, le récepteur doit être remplacé.

Questions & réponses

Questions fréquemment posées

Quelle est la différence entre les codes 82 et 83 ?

Le code 82 signifie que le récepteur GNSS ou son antenne est lui-même défectueux — anomalie interne, court-circuit sur l’antenne externe ou absence de connexion à celle-ci. Le code 83 signifie que le récepteur fonctionne, mais n’a reçu aucune donnée de position pendant trois heures de conduite cumulée. Consultez GNSS manquant (code 83) pour plus de détails.

Puis-je continuer à conduire avec une anomalie GNSS interne (code 82) ?

Le manuel la classe comme étant de gravité moyenne : acquittez le message et consultez un atelier agréé. Il ne s’agit pas d’une anomalie qui exige un arrêt immédiat, mais vous devez prendre rapidement rendez-vous pour le contrôle plutôt que de la laisser se reproduire.

Que signifie le DTC 000C31 sur un Stoneridge SE5000 ?

Le DTC 000C31 est le code d’atelier Stoneridge SE5000 correspondant à une anomalie GNSS interne — le récepteur GNSS interne a cessé de fournir des données de position. La procédure consiste à couper puis rétablir l’alimentation du tachygraphe et à effectuer un essai routier ; si l’anomalie persiste, le récepteur doit être remplacé.

Quelles sont les causes d’une anomalie GNSS interne sur un tachygraphe numérique ?

Selon le manuel, trois causes peuvent déclencher le code 82 : une anomalie interne du dispositif GNSS propre au tachygraphe, un court-circuit sur l’antenne GNSS externe (si elle est installée) ou l’absence de connexion à l’antenne GNSS externe.
