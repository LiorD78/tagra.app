Questions fréquentes sur l’installation
Sur quelles versions de Windows TAGRA fonctionne-t-il ?
TAGRA fonctionne sous Windows 10 et Windows 11. Il s’agit d’une application de bureau : elle s’installe sur l’ordinateur, et non dans un navigateur, et fonctionne hors ligne une fois installée.
Pourquoi dois-je installer Firebird et Desktop Runtime ?
Firebird est la base de données qui stocke les données de votre tachygraphe sur votre propre ordinateur, et Microsoft Desktop Runtime est le composant sur lequel l’application elle-même s’exécute. Tous deux sont installés automatiquement dans le cadre de l’installation de TAGRA : vous n’avez pas besoin de les télécharger séparément. S’ils sont déjà installés sur l’ordinateur, le programme d’installation ignore cette étape.
Puis-je installer TAGRA sur plusieurs ordinateurs ?
Oui. La licence autorise l’installation sur plusieurs ordinateurs au sein d’une même entreprise. La base de données peut être partagée sur le réseau local, afin que plusieurs personnes travaillent avec les mêmes données au lieu de conserver des copies séparées.
Où puis-je trouver ma clé de licence ?
La clé est délivrée après l’achat et est saisie directement dans le menu de licence du logiciel. Pendant l’essai de 30 jours, aucune clé n’est nécessaire : le logiciel complet fonctionne sans restriction.
L’installation de TAGRA nécessite-t-elle des droits d’administrateur ?
Oui. L’installation écrit dans Program Files et enregistre le service de base de données ; le compte utilisé pour effectuer l’installation doit donc disposer de droits d’administrateur sur l’ordinateur. L’utilisation quotidienne ne les nécessite pas par la suite.
Je suis bloqué pendant l’installation : qui peut m’aider ?
Notre équipe d’assistance technique vous aide directement. Écrivez à helpdesk@tagra.app en indiquant à quelle étape de l’installation le problème apparaît : une capture d’écran de l’erreur accélère considérablement le traitement.
